Schema-driven, accessible data table for React — tek endpoint'ten kolon, filter, sort, include, pagination ve form metadata'sını okuyup tabloyu otomatik kurar. Tailwind v4, zero runtime dependencies, TypeScript-first.

---

## Schema-driven nedir?

Backend bir `/api/v1/schema/{resource}` endpoint'i sunar; her field için tüm metadata tek yerdedir:

```json
{
  "data": {
    "type": "articles",
    "labels": { "singular": "Makale", "plural": "Makaleler" },
    "fields": {
      "title": {
        "type": "string",
        "label": "Başlık",
        "in": ["list", "show", "create", "update"],
        "sortable": true,
        "searchable": true,
        "filter": { "operator": "partial" },
        "form": { "input": "text", "required": true, "max": 255 }
      }
    },
    "relations": {
      "category": { "type": "belongs_to", "target": "categories", "label": "Kategori", "default_loaded": true, "in": ["list", "show"] }
    },
    "virtual_filters": [
      { "field": "search", "operator": "fulltext", "label": "Arama", "min_length": 2 }
    ],
    "endpoints": {
      "list": { "method": "GET", "path": "", "default_sort": "-published_at", "pagination": { "default_size": 15, "max_size": 100 } }
    }
  }
}
```

Frontend tarafı sadece şu kadar:

```tsx
<DataTable endpoint="/api/v1/articles" />
```

Otomatik gelen davranışlar:

- Sütun başlıkları, filter chip'leri, search placeholder — schema label'larından
- Sortable kolonlar — `field.sortable === true`
- Default sort — `endpoints.list.default_sort`
- Filter UI türleri — `field.filter.operator`'a göre (date / select / boolean / text)
- Async select option'ları — `field.source` lookup endpoint'inden
- Relation render — `name` / `title` / `slug` otomatik
- Default visible kolon kontrolü — `field.default_visible: false`
- Pagination param'ları — `pagination.number_parameter / size_parameter`
- Title — `labels.plural`

## Öne çıkanlar

- **Schema-driven** — backend tek doğruluk kaynağı; frontend kolon yapılandırması yapmaz
- **Compound API** — `<DataTable.Root>`, `.Header`, `.Body`, `.Row`, `.Cell`, `.Toolbar`, `.Search`, `.FilterBar`, `.Pagination` vb. tam markup kontrolü için
- **Headless hook** — `useDataTable`, `useAutoColumns`, `useSchema` — kendi render'ını kur
- **Spatie Query Builder adapter** — `filter[X]=Y`, `sort=-X`, `include=a,b`, `page[size]=N`
- **16 filter operatörü** — eq, neq, gt, gte, lt, lte, contains, starts_with, ends_with, in, not_in, between, is_null, is_not_null, is_true, is_false
- **Multi-sort** — Shift/Cmd + tıklama
- **Selection** — single / multiple, controlled & uncontrolled
- **URL sync** — Next.js / React Router / manuel adapter
- **Density** — compact / comfortable / spacious
- **Variants** — default / bordered / striped / minimal
- **Sticky header & footer** — container `maxHeight` ile aktif
- **Custom columns** — render override, accessor, label, width, sticky, align
- **Added columns** — select / drag / actions / expander
- **Auto relation render** — `category.name` / `tags[].name` otomatik çıkarım
- **i18n** — tüm label'lar schema'dan (UI generic yazılar için ayrı)
- **Tailwind v4** — zinc-only paleti, `rounded-sm`, modern utility-first
- **Zero runtime deps** — `clsx` + `tailwind-merge` pre-bundled
- **TypeScript-first** — generic over row shape, schema tip-safe
