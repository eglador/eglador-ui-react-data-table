# Getting Started

Your first DataTable example, enriched with custom columns, plus headless mode.

---

## Simplest usage

Schema-driven mode. The frontend configures no columns at all — everything comes from the schema:

```tsx
import { DataTable } from "eglador-ui-react-data-table";

export default function ArticlesPage() {
  return <DataTable endpoint="/api/v1/articles" />;
}
```

The schema endpoint is inferred automatically: `/api/v1/articles` → `/api/v1/schema/articles`. To set it manually:

```tsx
<DataTable
  endpoint="/api/v1/articles"
  schemaEndpoint="/api/v1/schema/articles"
/>
```

---

## Auth headers

```tsx
<DataTable
  endpoint="/api/v1/articles"
  headers={() => ({ Authorization: `Bearer ${getToken()}` })}
/>
```

When `headers` is a function it's called on every request (safe for token rotation).

## Toolbar features

Toggle them on or off:

```tsx
<DataTable
  endpoint="/api/v1/articles"
  search                  // search box
  filters                 // filter chip bar + Add filter
  refresh                 // refresh button
  density                 // compact/comfortable/spacious toggle
  columnVisibility        // column visibility menu
  pagination              // pagination bar
/>
```

## Custom column — render override

Customize values coming from the schema:

```tsx
<DataTable
  endpoint="/api/v1/articles"
  customColumns={[
    {
      field: "cover_image",
      width: 56,
      hideable: false,
      render: (value) => (
        <img src={String(value)} alt="" className="w-9 h-9 rounded-sm object-cover" />
      ),
    },
    {
      field: "title",
      minWidth: 280,
      render: (_value, row) => (
        <div className="flex flex-col gap-0.5">
          <span className="font-medium text-zinc-900">{row.title}</span>
          <span className="text-xs text-zinc-500">{row.slug}</span>
        </div>
      ),
    },
    {
      field: "status",
      render: (value) => (
        <span className="px-2 h-6 rounded-sm bg-zinc-100 text-xs uppercase">
          {String(value)}
        </span>
      ),
    },
  ]}
/>
```

`customColumns` enrich fields that are already in the schema; **fields not in the schema do not appear in the table**. If you don't supply a label, the schema's `field.label` is used.

## Added columns — select, actions, drag

Extra columns that aren't in the schema:

```tsx
<DataTable
  endpoint="/api/v1/articles"
  selection="multiple"
  addColumns={[
    { field: "select", type: "select", position: "start" },
    {
      field: "actions",
      type: "actions",
      position: "end",
      label: "Actions",
      render: (_v, row, ctx) => (
        <div className="flex gap-1 justify-end">
          <button onClick={() => editArticle(row.id)}>Edit</button>
          <button onClick={async () => {
            await deleteArticle(row.id);
            ctx.refresh();
          }}>
            Delete
          </button>
        </div>
      ),
    },
  ]}
/>
```

Sticky positioning defaults: `select` start (sticky left), `actions` end (sticky right).

## Bulk actions

```tsx
<DataTable
  endpoint="/api/v1/articles"
  selection="multiple"
  bulkActions={({ rows, clear }) => (
    <>
      <button onClick={() => archiveAll(rows)}>Archive ({rows.length})</button>
      <button onClick={clear}>Clear selection</button>
    </>
  )}
/>
```

Appears above the toolbar whenever one or more rows are selected.

## URL sync

Filter, sort, and pagination state mirror into the URL — state survives a page reload:

```tsx
<DataTable
  endpoint="/api/v1/articles"
  urlSync                                 // or { paramPrefix: "art_" }
/>
```

If multiple DataTables live on the same page, use distinct prefixes: `urlSync={{ paramPrefix: "art_" }}` and `urlSync={{ paramPrefix: "usr_" }}`.

## Compound API — full markup control

Lay out the toolbar / pagination / body yourself:

```tsx
import {
  DataTable,
  useDataTable,
  useSchema,
  inferSchemaEndpoint,
} from "eglador-ui-react-data-table";

function CustomTable() {
  const { schema } = useSchema(inferSchemaEndpoint("/api/v1/articles"));
  // ... build your own source/columns, get state via useDataTable ...

  return (
    <DataTable.Root table={table}>
      <DataTable.Toolbar>
        <DataTable.Search />
        <DataTable.FilterBar />
        <div className="ml-auto">
          <DataTable.RefreshButton />
          <DataTable.ColumnVisibilityMenu />
        </div>
      </DataTable.Toolbar>

      <DataTable.Container stickyHeader maxHeight={600}>
        <DataTable.Table>
          <DataTable.Header />
          <DataTable.Body />
          <DataTable.Footer />
        </DataTable.Table>
      </DataTable.Container>

      <DataTable.Pagination />
    </DataTable.Root>
  );
}
```

## Headless mode — `useDataTable`

For fully custom rendering, use just the state machine:

```tsx
import { useDataTable, useDataSource, laravelAdapter } from "eglador-ui-react-data-table";

function HeadlessTable() {
  const source = useMemo(
    () => laravelAdapter({ endpoint: "/api/v1/articles" }),
    []
  );

  const table = useDataTable({
    source,
    columns: [
      { id: "title", accessorKey: "title", header: "Title", sortable: true },
      { id: "status", accessorKey: "status", header: "Status" },
    ],
    initialState: {
      pagination: { mode: "offset", page: 1, pageSize: 25 },
    },
    selection: { mode: "multiple" },
  });

  return (
    <div>
      {table.rows.map((row) => (
        <div key={row.id}>{row.title}</div>
      ))}
      <button onClick={() => table.pagination.next()}>Next</button>
    </div>
  );
}
```

Renders no DOM — just state + helpers.
