# Installation

Package installation, peer dependencies, and Tailwind v4 integration.

---

## 1. Install the package

```bash
npm install eglador-ui-react-data-table
```

```bash
yarn add eglador-ui-react-data-table
```

```bash
pnpm add eglador-ui-react-data-table
```

## 3. Add `@source` for Tailwind v4

Tailwind needs to scan classes inside the package. Add the `@source` directive to your global stylesheet:

```css
@import "tailwindcss";

@source "../node_modules/eglador-ui-react-data-table";
```

## 4. Server components note (Next.js)

The component is marked `"use client"` (it uses `useState` / `useEffect`). Place it inside a client component, or import it from a file that already has the `"use client"` directive at the top.

---

## 5. Backend side

DataTable is powered by a **schema endpoint**. Your backend must expose:

- **Schema endpoint** (e.g. `/api/v1/schema/articles`) — resource metadata
- **List endpoint** (e.g. `/api/v1/articles`) — data shaped for Spatie Query Builder

See the [Welcome](?path=/docs/welcome--docs) page for the schema structure. A reference Laravel backend is available in the `eglador-cms-laravel` package.

Default param conventions (Spatie Query Builder):

- `?filter[field]=value` — filter
- `?sort=-field` — descending sort
- `?include=rel1,rel2` — eager-load relations
- `?page[number]=1&page[size]=15` — pagination
