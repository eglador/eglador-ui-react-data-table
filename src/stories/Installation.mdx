# Installation

Paket kurulumu, peer dependency'ler ve Tailwind v4 entegrasyonu.

---

## 1. Paketi kur

```bash
npm install eglador-ui-react-data-table
```

```bash
yarn add eglador-ui-react-data-table
```

```bash
pnpm add eglador-ui-react-data-table
```

## 3. Tailwind v4 için `@source` ekle

Tailwind, paket içindeki sınıfları tarayabilmek için `@source` direktifine ihtiyaç duyar. Global stylesheet'inize ekleyin:

```css
@import "tailwindcss";

@source "../node_modules/eglador-ui-react-data-table";
```

## 4. Server components notu (Next.js)

Bileşen `"use client"` ile işaretlenmiştir (`useState` / `useEffect` kullanır). Onu bir client component içine veya `"use client"` direktifi olan bir dosyaya yerleştirin.

---

## 5. Backend tarafı

DataTable, **schema endpoint**'ten beslenir. Backend'inizin şu yapıyı sunması gerekir:

- **Schema endpoint** (örn. `/api/v1/schema/articles`) — kaynak metadata'sı
- **List endpoint** (örn. `/api/v1/articles`) — Spatie Query Builder uyumlu veri

Schema yapısı için [Welcome](?path=/docs/welcome--docs) sayfasındaki örneğe bakın. Laravel için referans backend implementasyonu eglador-cms-laravel paketinden alınabilir.

Default param konvansiyonu (Spatie Query Builder):

- `?filter[field]=value` — filter
- `?sort=-field` — desc sort
- `?include=rel1,rel2` — eager-load relations
- `?page[number]=1&page[size]=15` — pagination
